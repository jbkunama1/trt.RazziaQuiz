🎯 trt.RazziaQuiz

Selbst gehostetes Live-Quiz im Kahoot-Stil — Buzzer, Manager-Dashboard, eigene Fragenkataloge.

🚀 Schnellstart

docker compose up -d

Danach erreichbar unter http://<host>:8093.

Manager öffnen Repository ansehen

🏗️ Architektur

  • Port: 8093 extern → 3000 intern (Nginx, Webroot + /ws-Proxy)
  • WebSocket: läuft nur intern auf Port 3001, wird von Nginx unter /ws durchgereicht
  • Netzwerk: highfishNetwork (extern)
  • Registry: GHCR (ghcr.io/jbkunama1/trt.razziaquiz)
  • CI/CD: GitHub Actions baut bei jedem Push auf main den aktuellen Upstream-Quellcode und veröffentlicht das Image
  • Healthcheck: curl -f http://localhost:3000/ (containerintern)

📦 Deployment mit Portainer

Stack in Portainer erstellen, Web-Editor verwenden und folgendes eintragen:

version: '3.8'

services:
  razzia-quiz:
    image: ghcr.io/jbkunama1/trt.razziaquiz:latest
    container_name: razzia-quiz
    restart: unless-stopped
    ports:
      - "8093:3000"
    environment:
      - WEB_ORIGIN=http://DEINE-DOMAIN:8093
      - SOCKET_URL=http://DEINE-DOMAIN:8093
    volumes:
      - razzia_quiz_config:/app/config
    networks:
      - highfishNetwork
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000/"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 40s

volumes:
  razzia_quiz_config:
    driver: local

networks:
  highfishNetwork:
    external: true

🔧 Umgebungsvariablen

VariableDefaultBeschreibung
WEB_ORIGINhttp://localhost:8093Öffentliche URL des Web-Interfaces (externer Port)
SOCKET_URLhttp://localhost:8093Öffentliche URL für die WebSocket-Verbindung (über /ws-Proxy, kein eigener Port)
