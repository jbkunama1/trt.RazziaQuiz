trt.RazziaQuiz

Containerized GHCR

🚀 Quick Start

Pull von GHCR

docker pull ghcr.io/jbkunama1/trt.RazziaQuiz:latest

Docker Compose

docker compose up -d

🏗️ Architektur

  • Port: 8033
  • Network: highfishNetwork (extern)
  • Registry: GHCR (ghcr.io/jbkunama1/trt.RazziaQuiz)
  • CI/CD: GitHub Actions (auto-build on push to main)

📦 Deployment mit Portainer

Stack in Portainer erstellen und folgenden YAML eintragen:

version: '3.8'

services:
  razzia-quiz:
    image: ghcr.io/jbkunama1/trt.RazziaQuiz:latest
    container_name: razzia-quiz
    restart: unless-stopped
    ports:
      - "8033:8033"
    environment:
      - NODE_ENV=production
      - PORT=8033
    volumes:
      - razzia_quiz_data:/app/data
    networks:
      - highfishNetwork
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8033/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 40s

volumes:
  razzia_quiz_data:
    driver: local

networks:
  highfishNetwork:
    external: true
